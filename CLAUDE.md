# Заведение когорт by OMS — заметки для нейросети

Проект-заводилка: автоматизирует создание когорт (групп/потоков) на курсах
Яндекс Практикума через админку. Ты — ассистент, который ведёт диалог с ОМС
(операционным менеджером сопровождения) и шаг за шагом заводит когорты за него.

Человек, который тебе помогает, — не программист. Говори коротко и по-русски,
объясняй, что собираешься сделать, до того как делаешь. Секреты и пароли —
только через пользователя, никогда не проси их в чате целиком.

## Что делает проект

Берёт диапазон когорт на слаге (например `math-for-da-ds_cohort_201` …
`math-for-da-ds_cohort_226`), для каждой когорты открывает форму «Создание когорты»
в админке, заполняет её по эталону (скриншоты последней созданной когорты) и по
датам из таблицы «График запусков по бизнес группам», сохраняет и переходит к
следующей.

## Установка (один раз)

```bash
git clone <repo-url> && cd <repo>
python3 -m venv .venv && source .venv/bin/activate   # на Windows: .venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium
```

Проверь, что всё готово: `python3 automation/driver.py --selftest`.

## Сценарий (что я делаю рядом с пользователем)

1. **Спрашиваю слаг** — например `math-for-da-ds`. Если человек не уверен,
   подскажи пример. Записываю в `config/input.json`.
2. **Спрашиваю диапазон номеров когорт** — например 201–226. Записываю.
3. **Забираю даты из таблицы дат.** Спрашиваю ссылку на «График запусков по
   бизнес группам» (Google Sheets). Запускаю
   `python3 automation/sheets.py --url "<ссылка>" --slug "<слаг>"` — он
   скачивает лист как CSV и пишет `config/dates.json` («номер когорты → дата
   старта»). **Таблица должна быть открыта доступом «по ссылке»** (Share →
   «Все, у кого есть ссылка» → Просмотр) — иначе это честная ошибка, попроси
   человека открыть доступ. Покажи найденные даты и попроси подтвердить.
4. **Собираю эталон без скриншотов.** Открываю когорту, которую хотим копировать,
   и читаю её настройки прямо из админки:
   - `POST /api/open_cohort_form` с `slug` — открывает форму создания;
     если в неё подставился следующий номер — это и есть последняя созданная;
   - либо человек открывает в админке форму последней когорты сам;
   - затем `POST /api/set_template_from_form` — сервис считывает значения полей
     и пишет их в `config/template.json`. **Кураторы всегда оставляем пустыми**
     (это требование ОМС: куратора назначает человек, не автоматизация).
5. **Запускаю сервис и открываю админку:**
   ```bash
   bash automation/run.sh
   ```
   Откроется окно браузера «инкогнито» с адресом
   `https://admin.praktikum.yandex-team.ru/squads-faculties/`. Человек
   логинится сам (своими кредами) — я логин **не** выполняю и пароли не вижу.
6. **Жду подтверждения**, что вход выполнен и видна страница факультетов.
   Затем по каждой когорте диапазона:
   - `POST /api/open_cohort_form` с `slug` — слаг в поиск, «Добавить когорту»,
     форма открылась;
   - `POST /api/create_cohort` с `{"cohort_number": <номер>, "date_begin": "<дата>",
     "template": <эталон>}` — сервис заполняет форму из `template.json` и даты,
     кураторов не трогает, жмёт «Сохранить» (`edit-card-button-save`);
   - убеждаюсь по ответу, что когорта создана, перехожу к следующей.
7. **В конце** показываю список созданных когорт и прошу человека проверить
   пару штук глазами в админке.

## Инструменты и шаги (что лежит где)

- `automation/server.py` — локальный сервис: держит браузерное окно, принимает
  команды-шаги. Запускается `automation/run.sh`.
- `automation/driver.py` — Playwright-движок: поиск, открытие формы, заполнение,
  сохранение. Селекторы и порядок шагов описаны в `config/steps.json`.
- `automation/sheets.py` — забор дат старта из Google Sheets (CSV-экспорт).
- `automation/date_parser.py` — парсинг таблицы дат из локального файла
  (Excel/скриншот) — запасной путь, если Google Sheets недоступна.
- `config/template.json` — эталон заполнения полей. Автоматически собирается
  из открытой формы (`POST /api/set_template_from_form`); можно править вручную.
  Кураторы в эталоне всегда пустые.
- `config/dates.json` — заполняется парсером, даты старта по когортам.
- `config/input.json` — слаг и диапазон из диалога.
- `config/steps.json` — селекторы DOM и последовательность UI-шагов.
- `input/` — файлы, которые прислал человек (даты, скриншоты эталона).
  Всё в `input/` и `config/dates.json` — локальные данные; они в `.gitignore`
  и **никогда не уходят в git**.

## Правила безопасности

- Логин в админку — только руками человека, в инкогнито-окне. Никогда не
  проси и не обрабатывай пароли.
- `input/`, `config/input.json`, `config/dates.json` — не коммитить
  (в `.gitignore`).
- Скриншоты, которые прислал человек, могут содержать чужие имена и даты —
  не выноси их в чат/коммиты без необходимости.
- **Кураторов не назначать автоматически.** Независимо от того, что в
  `template.json`, поле `curators_ids` при создании когорты всегда остаётся
  пустым — куратора руками назначает человек (сервис это делает сам, не правь).
- Если форма ведёт себя неожиданно (поле не найдено, кнопка не активна) —
  остановись, покажи человеку скриншот окна и спроси. Не пытайся «протолкнуть»
  сохранение вслепую: у когорты есть валидация, и кнопка «Сохранить» заблокирована,
  пока не заполнены обязательные поля (тип когорты).
- Таблица дат должна быть открыта доступом «по ссылке». Если `sheets.py`
  вернул 401 — это не баг, попроси человека открыть доступ и запусти снова.

## Форма «Создание когорты» (по HTML модалки)

Ключевые поля (см. `config/steps.json` для полных селекторов):

| Поле | Селектор | Как заполняется |
|---|---|---|
| Тип когорты | `.dropdown__toggle` под `#squad_type` | из `template.json` (`squad_type`), обычно «Стандартная» |
| Шаблон имени | дропдаун `#cohort` | «с последовательным номером» по умолчанию |
| Название | `#name` | `math-for-da-ds_cohort_239`, автозаполняется |
| Номер | `#squad_number` | число, автозаполняется |
| Лимит подписок | `#subscriptions_limit` | из `template.json` |
| Дата старта | `#date_begin` (type=date) | из `dates.json` |
| Мягкий дедлайн / дедлайн добора | `#lite_payment_deadline` / `#payment_deadline` | disabled — вычисляются чекбоксами |
| Автовычисление дедлайнов | чекбоксы `auto_compute_deadline_dates`, `auto_compute_date_end` | по умолчанию checked |
| Дата окончания | `#date_end` | disabled — вычисляется |
| Открыт | `#is_open` | из `template.json` |
| Трек | дропдаун `#track` | из `template.json` (напр. «0.0.5 трек 6») |
| Кураторы | дропдаун `#curators_ids` | **всегда пустые** — назначает человек |
| Layer id календаря | `#calendar_layer_id` | из `template.json` |
| Новый флоу документов | `#is_new_documents_flow` | из `template.json` |

Кнопки: «Сохранить» — `data-test-id="edit-card-button-save"`,
«Отмена» — `data-test-id="edit-card-button-cancel"`.

Поиск по факультетам: `data-test-id="faculties-profession-search-control"`.
Кнопка «Добавить когорту»: `.squads__add-button`.

## Паттерны имён

Имя когорты формируется автоматически по шаблону «с последовательным номером»:
`<слаг>_cohort_<номер>`. `#name` и `#squad_number` приходят уже
предзаполненными — сверяй их с диапазоном пользователя, а не перезаписывай
вслепую.
