# Заведение когорт by OMS

Автоматизация заведения когорт (групп/потоков) на курсах Яндекс Практикума.
Работает через любую нейросеть (Claude Code, ChatGPT, Gemini…): открываешь
проект в ассистенте, говоришь слаг и диапазон когорт — ассистент ведёт диалог
и заводит когорты за тебя.

**Сделано по образцу [free-my-tv](https://github.com/simbasjungles/free-my-tv)**:
проект спроектирован так, чтобы его «оживлял» AI на естественном языке.

## Что ты получаешь

- Экономию времени: завести 25 когорт вручную ≈ 40 минут; с заводилкой —
  несколько минут диалога.
- Пошаговую навигацию: ассистент сам открывает форму, заполняет, сохраняет и
  переходит к следующей когорте.
- Безопасный вход: логин в админку **только тобой**, вручную, в инкогнито-окне.
  Пароли не обрабатываются и никуда не передаются.
- Эталон заполнения: настройки (трек, кураторы, чекбоксы) считываются прямо
  из админки из когорты-эталона (± ничего вставлять не нужно); кураторы при
  создании всегда остаются пустыми.
- Даты старта: автоматически забираются из присланного файла таблицы
  «График запусков по бизнес группам» — скриншот (OCR) или Excel-файл.

## Установка

```bash
git clone https://github.com/<твой-профиль>/praktikum-cohort-factory && cd praktikum-cohort-factory
python3 -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium
```

Проверка: `python3 automation/driver.py --selftest`.

Нужен только Python 3.10+.

## Запуск (через нейросеть — рекомендуемый способ)

1. Открой папку проекта в своём ассистенте (Claude Code: `claude` в этой папке)
   и скажи, что хочешь завести когорты.

   Примеры запросов:

   - «Заведи когорты 201–226 на math-for-da-ds по графику запусков».
   - «Создай когорты на python-basics, эталон — как у последней когорты».

2. Ассистент спросит:
   - **слаг** (курс), например `math-for-da-ds`;
   - **диапазон номеров когорт**, например 201–226;
   - **файл с датами** — скриншот таблицы «График запусков по бизнес группам»
     или сам Excel-файл (таблица приватна и по ссылке не открывается); если
     скриншот — ассистент распознаёт даты через OCR;
   - **какую когорту взять эталоном** — её настройки сервис считает из админки
     сам (скриншоты не нужны).

3. Ассистент запустит `bash automation/run.sh` — откроется инкогнито-окно с
   админкой. Ты логинишься сам.

4. Дальше ассистент всё делает сам: триггерит чтение эталона из админки,
   заполняет формы по датам из таблицы (кураторов не трогает) и сохраняет.
   Ты подтверждаешь шаги и в конце проверяешь пару когорт глазами.

Хочешь без нейросети? Ручной режим описан в [РУЧНОЙ-РЕЖИМ.md](docs/РУЧНОЙ-РЕЖИМ.md).

## Что внутри

```
automation/     сервис и движок (run.sh, server.py, driver.py, sheets.py, date_parser.py)
config/         template.json — эталон полей; steps.json — селекторы и шаги
input/          локальные данные (аварийные скриншоты) — в git не попадают
docs/           документация
```

## Безопасность

- Вход в админку — только вручную, человеком. Ассистент не видит пароли.
- `input/`, `config/input.json`, `config/dates.json` — локальные, в `.gitignore`.
- Если форма ведёт себя неожиданно — ассистент останавливается и спрашивает тебя.
