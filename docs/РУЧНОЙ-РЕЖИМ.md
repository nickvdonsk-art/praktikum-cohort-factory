# Ручной режим (без нейросети)

Заводилка рассчитана на управление через нейросеть, но базовые шаги можно
выполнять и вручную: поднять сервис, открыть окно, кликать по API.

## Требования

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium
```

## Запуск

```bash
bash automation/run.sh
```

Сервис слушает только `127.0.0.1:8742`. Открой http://127.0.0.1:8742/docs —
там Swagger с кнопкой «Try it out»: можно вручную звать эндпоинты.

## Последовательность

1. `POST /api/open` — откроется инкогнито-окно
   `https://admin.praktikum.yandex-team.ru/squads-faculties/`. Залогинься сам.
2. `GET /api/snapshot` — посмотреть текстовый снимок страницы (что видно сейчас).
3. `POST /api/search_slug` `{"slug": "math-for-da-ds"}` — слаг в поиск,
   «Добавить когорту», форма открылась (или `POST /api/open_cohort_form`).
4. Эталон на лету: `GET /api/current_form` — прочитать заполненные поля
   открытой формы; `POST /api/set_template_from_form` — сохранить их в
   `config/template.json`.
5. Заполняй вручную (если хочешь): `POST /api/select` (дропдауны: `#squad_type`,
   `#track`), `POST /api/type` (`#name`, `#squad_number`, `#date_begin`, …),
   `POST /api/tick` (чекбоксы). Кураторов НЕ трогай.
6. `POST /api/create_cohort` — за одну команду открывает форму (если не открыта),
   заполняет по `config/template.json` и дате, сохраняет. Кураторы пустые.
7. `GET /api/screenshot` — скриншот, если что-то пошло не так.

Даты из Google Sheets:

```bash
python3 automation/sheets.py --url "https://docs.google.com/spreadsheets/d/<ID>" --slug math-for-da-ds
```

Таблица должна быть открыта доступом «по ссылке» (иначе 401). Запасной путь —
локальный файл: `python3 automation/date_parser.py --slug <слаг> --file <имя в input/dates/>`.
