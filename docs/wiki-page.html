Как это работает

Схема простая: ты задаёшь параметры — остальное делает нейросеть.

Ты говоришь: слаг (курс) и диапазон номеров
↓
Нейросеть собирает контекст: даты из таблицы + эталон из админки
↓
Ты сам логинишься в админку в открытом окне
↓
Нейросеть заполняет и сохраняет когорту за когортой (кураторов не трогает)
↓
Ты проверяешь глазами пару созданных когорт

Установка

Один раз, ~5 минут. Нужен только Python 3.10+.

# 1. Склонировать проект
git clone https://github.com/nickvdonsk-art/praktikum-cohort-factory && cd praktikum-cohort-factory

# 2. Виртуальное окружение
python3 -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate

# 3. Зависимости
pip install -r requirements.txt

# 4. Браузер для автоматизации
playwright install chromium

Проверка, что всё готово:

python3 automation/driver.py --selftest
✅ Всё работает Ты открываешь папку проекта в Claude Code (команда claude в этой папке) и просто говоришь, что нужно сделать. Дальше нейросеть ведёт диалог.

Первый запуск

Три шага, в которых нужно только ты — остальное нейросеть делает сама.

1
Открываешь проект в нейросети
В папке проекта запускаешь Claude Code и говоришь: «Хочу завести когорты».
2
Отвечаешь на вопросы и прикладываешь файл с датами
Нейросеть спросит: слаг (например math-for-da-ds), диапазон номеров (например 201–226) и какую когорту взять эталоном. Ещё попросит скриншот или Excel-файл таблицы «График запусков по бизнес группам» (она приватна и по ссылке не открывается) — из него нейросеть заберёт даты.
3
Входишь в админку и подтверждаешь
Откроется окно браузера со страницей факультетов — ты логинишься своими руками. Подтверждаешь вход, дальше нейросеть создаёт когорты и в конце показывает список — ты проверяешь пару штук глазами.
⚠ Кураторы — всегда руками человека Поле «Кураторы» при создании когорт автоматика никогда не заполняет (сервис гарантирует это сам, даже если в эталоне кто-то его заполнил). Куратора назначает человек после создания когорты. Это требование ОМС.

Примеры запросов

Просто скажи нейросети, что нужно:

«Заведи когорты 201–226 на math-for-da-ds по графику запусков»
«Создай когорты на python-basics, эталон — как у последней когорты»

Частые вопросы

Что делать, если что-то пошло не так.

Нейросеть просит логин и пароль от админки — это нормально?›
Нет. Вход всегда делаешь только ты, своими руками, в отдельном окне браузера. Если ассистент просит пароль — останови его и скажи: «Вход делаю сам».
«Кнопка Сохранить заблокирована» — что это значит?›
Когорта не прошла валидацию (например, не заполнен тип когорты). Нейросеть остановится и покажет скриншот — дозаполни пропущенное поле и продолжи.
«Форма подставила другой номер» — что делать?›
Сервис намеренно не перезаписывает номер вслепую: он покажет, что видит в форме, и спросит тебя. Сверься с диапазоном и на всякий случай проверь, нет ли уже такой когорты.
Могу ли я заводить когорты без нейросети?›
Да, есть ручной режим через Swagger-интерфейс (описан в docs/РУЧНОЙ-РЕЖИМ.md репозитория). Но удобнее и быстрее — через нейросеть.
Это безопасно для чувствительных данных?›
Да. Все локальные данные (скриншоты, загруженные таблицы, даты) лежат только у тебя на компьютере и не попадают в git. В репозиторий уходит только код. Пароли в админку вводишь только ты.
