Кратко о крутом инструменте

© Николай Дубинин, 2026

Что это?

  • Автоматизированный сервис создания когорт (потоков) в Яндекс Практикуме.
  • Работает через локальный сервис‑прокси и Playwright‑драйвер.
  • Выполняет весь цикл: парсинг дат, открытие админки, заполнение формы, сохранение.

Ключевые возможности

  • Одним запросом собирает все 5 входных параметров.
  • Парсит Excel/xlsx‑файлы с графиком запусков.
  • Детектирует логин пользователя, ждёт вход в админку.
  • Создаёт диапазон когорт без пауз и ручных подтверждений.
  • Отчёт в конце с перечнем созданных когорт.

Технический стек

  • Python 3, виртуальное окружение.
  • Playwright + Chromium (инкогнито‑режим).
  • Pandas + Openpyxl для парсинга Excel.
  • Локальный HTTP‑сервер (`automation/server.py`).
  • REST‑API (`/api/*`) для управления браузером.

Пользовательский сценарий

  1. Пользователь вводит слаг курса, ссылку на страницу, диапазон номеров, эталонную когорту и файл‑таблицу.
  2. Скрипт сохраняет `config/input.json` и запускает `date_parser.py`.
  3. Запускается `automation/run.sh`; пользователь логинится в окно браузера.
  4. Сервис автоматически создаёт все когорты, используя шаблон из `template.json`.
  5. По завершении – выводит список созданных когорт.

Плюсы для коллег

  • Сокращает рутину – создаёт десятки когорт за секунды.
  • Исключает человеческие ошибки в датах и номерах.
  • Унифицирует параметры всех когорт (тип, настройки, кураторы).
  • Легко адаптировать под любой курс, просто менять входные данные.

Как запустить?

git clone <repo‑url>
cd <repo>
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium
python3 automation/driver.py --selftest
# затем `python3 automation/date_parser.py …` и `bash automation/run.sh`

Дальнейшее развитие
